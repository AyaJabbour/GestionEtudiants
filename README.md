# GestionEtudiants

## Projet de Kanban

Ce dépôt contient une implémentation simple d'un tableau Kanban en HTML/CSS/JavaScript.

### Utilisation

1. Ouvrir `/home/runner/work/GestionEtudiants/GestionEtudiants/index.html` dans un navigateur.
2. Ajouter une tâche via le champ de saisie.
3. Déplacer une tâche entre les colonnes avec le glisser-déposer.
